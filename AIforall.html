AI For All Project

Smart Waste Segregation System

This project is an AI-powered waste segregation system developed using Google Teachable Machine, MIT App Inventor, Arduino UNO, and HC-05 Bluetooth Module.

The system identifies whether waste is Dry Waste or Wet Waste using a machine learning model trained in Google Teachable Machine.

Technologies Used

  • Google Teachable Machine
  • MIT App Inventor
  • Arduino UNO
  • HC-05 Bluetooth Module
  • Machine Learning
  • Artificial Intelligence

How It Works

  1. User opens the mobile application.
  2. Camera captures the waste object.
  3. Google Teachable Machine classifies the waste.
  4. The app determines whether it is Dry Waste or Wet Waste.
  5. The result is sent to Arduino UNO through HC-05 Bluetooth.
  6. Dry Waste LED lights up for dry waste.
  7. Wet Waste LED lights up for wet waste.
